# vtl/

Thur VTL — the Virtual Tape Library product: a spec-conformant SMC-3
medium changer + SSC-4 LTO drives presented as an iSCSI target.
`daemon/` is `thurvtld`, `cli/` is the `thurvtl` CLI, `scripts/`
holds the integration tests.

[`README.md`](../README.md).
