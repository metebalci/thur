# Thur documentation

Documentation for **Thur VTL** (virtual tape library) and **Thur VSA**
(virtual storage appliance), organized into four sets by audience. Start
with whichever matches what you're doing — each set's `README.md` is its
index and reading order.

- **[Quick Start](QUICKSTART.md)** — install to a working virtual device
  in a few minutes, on one machine, with the `local` backend.
- **[Admin Guide](admin/)** — operating it: installation, configuration,
  storage backends, connecting hosts, VTL/VSA operations, security,
  monitoring, disaster recovery, troubleshooting, production-readiness.
- **[Reference](reference/)** — how it works: the wire spec, SCSI / NVMe
  conformance, and the storage / dedup / backpressure / transport
  internals.
- **[Developer](dev/)** — building from source, the test suite, releasing.
