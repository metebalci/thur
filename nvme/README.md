# nvme/

NVMe crates (Thur VSA only). `nvme-base` (NVMe Base Spec wire
primitives), `nvme-nvm` (NVM Command Set dispatch), `nvme-tcp`
(NVMe/TCP transport) — the NVMe-oF alternative to VSA's iSCSI front.

Conformance: [`docs/CONFORMANCE_NVME.md`](../docs/CONFORMANCE_NVME.md).
Transport design: [`docs/NVMETCP.md`](../docs/NVMETCP.md).
