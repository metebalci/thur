# vsa/

Thur VSA — the Virtual Storage Appliance product: SBC-3
direct-access block LUNs over iSCSI or NVMe-TCP, backed by the
shared dedup-capable chunk pool. `daemon/` is `thurvsad`, `cli/` is
the `thurvsa` CLI, `scripts/` holds the integration tests.

Start at [`CLAUDE.md`](../CLAUDE.md) and the root
[`README.md`](../README.md).
